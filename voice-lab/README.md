# ISAAC Voice Lab

Standalone, local-only voice audition utility. It is not connected to ISAAC Core or Home.

Runtime and models live outside Git in the Windows Documents folder under `ISAAC Voice Lab Data`.

Included audition engines:

- Kokoro-82M v1.0 ONNX: Adam, Michael, George, and Lewis.
- Piper: Joe medium and Norman medium.

Use the voice dropdown, edit the multiline text, adjust the native inference speaking-rate control, and select **Speak**. The most recent WAV is saved in `ISAAC Voice Lab Data\output\audition.wav` under the Windows Documents folder.
